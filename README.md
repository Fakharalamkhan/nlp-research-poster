# Knowing When to Revise: Confidence-Gated Self-Correction in LLMs (Research Poster)

Research poster (DIN A1, portrait) and appendix for the NLP module at the University of Trier.
Fakhr E Alam Khan, Matriculation No. 1818211.

The poster reports an empirical study of confidence-gated self-correction with Qwen2.5-7B-Instruct on
GSM8K and HotpotQA. This repository is self-contained: the experiment code, prompts, data splits, raw model
outputs and all result tables are in [`experiments/`](experiments/).

![Poster preview](poster_preview.png)

## Files

- `poster.tex` / `poster.pdf`: the poster (beamerposter, 594 x 841 mm). All charts and diagrams are vector graphics.
- `appendix.tex` / `appendix.pdf`: references (numbered as on the poster), the list of generative AI tools used, and the declaration form (pre-filled, unsigned in this repository).
- `references.bib`: bibliography.
- `declaration/`: the official declaration form (`declaration_form_blank.pdf`) and `declaration_prefilled.tex`, which types the known fields into it.
- `numbers_sources.md`: every number on the poster and the file in `experiments/` it comes from.
- `verify_poster.py`: checks page size, smallest font size (at least 24 pt) and raster image resolution.
- `build.sh`: builds the poster, the pre-filled declaration and the appendix.
- `make_submission.sh`: builds `1818211.zip` (poster + appendix with the signed declaration) in `../poster_submission/`, outside this repository.
- `experiments/`: everything needed to reproduce the results (see below).

## Experiments

- `experiments/cgsc/`: Python package: dataset loading (`data/` holds the 500 sampled questions per dataset and the 100 dev / 400 test split, seed 42), prompts (`prompts/`), answer extraction and scoring, the inference pipeline (`run.py`), sanity checks and the analysis (`analyze.py`, `generate_table6.py`).
- `experiments/kaggle/`: the Kaggle notebook used for inference (2x NVIDIA T4, vLLM 0.6.6.post1) and the script that generates it.
- `experiments/results/`: raw per-question outputs (`raw/qwen_gsm8k.jsonl`, `raw/qwen_hotpotqa.jsonl`), `summary.json`, result tables (`tables/*.csv`), figures, sanity reports and environment metadata.

Model: `Qwen/Qwen2.5-7B-Instruct` in 16-bit precision. Datasets: GSM8K (`main`, test split) and HotpotQA
(`distractor`, validation split), 500 questions each. Llama-3.1-8B-Instruct was planned but not run; its code
paths remain but are unused.

### Reproduction

**How the reported results were produced.** The results in `results/raw/` came from two runs. The first run
executed the full pipeline, but a seeding bug made all ten self-consistency samples identical. We then re-ran
only the self-consistency samples on top of the first run's outputs (`python cgsc/run.py ... --resample_sc_only`),
which recomputes the self-consistency scores and majority voting; everything else (initial answer, verbalised
confidence, P(True), revision, IoE) comes from the first run. With the fixed code, running the notebook with its
default settings reproduces all results in a single pass.

1. **Inference.** Run `experiments/kaggle/cgsc_run.ipynb` on Kaggle with 2x NVIDIA T4 GPUs and internet access
   (default `SETTINGS = ["qwen/gsm8k", "qwen/hotpotqa"]`). It writes `qwen_gsm8k.jsonl` and `qwen_hotpotqa.jsonl`;
   copy them to `experiments/results/raw/`. The notebook is generated by `python kaggle/build_notebook.py`.
2. **Analysis.** From `experiments/`:
   ```bash
   python cgsc/analyze.py
   python cgsc/generate_table6.py
   ```
   This regenerates `results/tables/*.csv`, `results/figures/` and `results/summary.json` from `results/raw/`.
   The scripts also write LaTeX versions of the tables into `experiments/paper/`; that folder is not used by the
   poster and is git-ignored.

## Build the poster

Requires a LaTeX distribution with beamerposter, pgfplots, qrcode and pdfpages, and Python with `pdfplumber` for the checks.

```bash
bash build.sh
python verify_poster.py
```
